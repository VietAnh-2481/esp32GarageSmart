KHAC PHUC LOI MO SKETCH

1) Khong mo truc tiep file ZIP bang Arduino IDE.
2) Giai nen toan bo ZIP ra mot thu muc binh thuong, vi du Desktop\SmartGarage_ArduinoIDE_Wokwi.
3) Trong Arduino IDE chon File > Open va mo file SmartGarage_ArduinoIDE_Wokwi.ino.
   Khong mo file sketch.ino neu ban dang lam viec trong Arduino IDE.
4) Neu muon dua len Wokwi, dung file sketch.ino va diagram.json.
5) Chon board ESP32 Dev Module/ESP32 DevKit V1 trong Arduino IDE neu muon Verify code.
6) Cai cac thu vien trong libraries.txt bang Library Manager.

Luu y: Arduino IDE khong doc diagram.json de tao mach; file nay dung cho Wokwi.
